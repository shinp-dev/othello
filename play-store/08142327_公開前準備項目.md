## Git / production deploy安全境界

- local commitだけでは外部状態は変わらない。
- feature branch pushでもCloudflare non-production buildとversion uploadが発生する。
- `main` pushは`landing-page`を`chanriva` Workerへ自動deployし、本番Webを変更する。必ずOWNER承認を得る。
- Cloudflareのproduction branchは`main`、rootは`landing-page`、監視pathは`*`。GitHub Actionsの通常CIはWebをdeployしない。
- `Research batch` workflowの手動実行はproduction Research DBを処理し得るためOWNER承認を得る。
- tag pushは通常CI対象。Cloudflare production deploy対象とは確認できないが、事前確認なしにpushしない。
