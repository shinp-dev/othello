# ちゃんりば 技術資料

このページは、ちゃんりばの設計・運用・リリース・監査資料を探すための唯一の入口です。現在の仕様や手順を説明する現役資料と、過去の判断・実施結果を保存する履歴資料を分けています。

## 初めて読む場合

1. システム全体を知る
   → [全体設計 / システム構成](01_全体設計/システム構成.md)
2. オンライン対局を知る
   → [オンライン対局 / 通常接続設計](02_オンライン対局/通常接続設計.md)
   → [オンライン対局 / 再接続設計](02_オンライン対局/再接続設計.md)
3. 製品の中核機能であるResearchを知る
   → [研究データ / 研究データ運用](03_研究データ/研究データ運用.md)
   → 設計時の判断経緯が必要な場合は[履歴 / 研究データ設計記録](09_履歴/研究データ設計記録.md)
4. 運用責務と障害確認先を知る
   → [全体設計 / 運用マップ](01_全体設計/運用マップ.md)
