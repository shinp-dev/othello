## トランザクション性

対象の`ALTER TABLE ADD COLUMN`、関数/ポリシーのCREATE/DROP、GRANT/REVOKEはPostgreSQL トランザクション内で実行可能です。`CREATE INDEX CONCURRENTLY`等のトランザクション外必須処理は含みません。

本番には`supabase_migrations.schema_migrations`が存在しないため、現在のまま`supabase db push`を実行してはいけません。CLIは001以降を未適用と判断する可能性があります。025はDashboard SQL Editorで全文を`begin;` / `commit;`で一括実行し、成功後に読み取り専用検証しました。

この実行単位なら、途中失敗、関数作成後の権限変更失敗、列追加後のRPC作成失敗はいずれもトランザクション全体がrollbackされ、partial 状態は残りません。`db push --dry-run`は保留中 fileの列挙であり、SQLを実行検証しない点にも注意します。
