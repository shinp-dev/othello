## Standard AI character presentation

Historical release note for the original level-based implementation. The current Player/OpponentPack
model, progress migration and presentation contract are documented in [opponent-packs.md](opponent-packs.md).

Adds animated opponent introductions and result reactions for Standard AI Lv1–Lv8 using the existing character assets. Introductions are shown once per user and level on the device. Match results show the corresponding confident or crying character, with first-clear unlock messaging.
