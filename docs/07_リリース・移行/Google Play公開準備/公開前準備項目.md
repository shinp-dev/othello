## Git / 本番 デプロイ安全境界

- 端末内 コミットだけでは外部状態は変わらない。
- feature ブランチ pushでもCloudflare 非本番 ビルドとバージョン アップロードが発生する。
- `main` pushは`landing-page`を`chanriva` ワーカーへ自動デプロイし、本番Webを変更する。必ず所有者承認を得る。
- Cloudflareの本番 ブランチは`main`、rootは`landing-page`、監視パスは`*`。GitHub Actionsの通常CIはWebをデプロイしない。
- `Research batch` ワークフローの手動実行は本番 Research DBを処理し得るため所有者承認を得る。
- tag pushは通常CI対象。Cloudflare 本番 デプロイ対象とは確認できないが、事前確認なしにpushしない。
